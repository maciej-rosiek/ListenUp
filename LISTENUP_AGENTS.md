# ListenUp agent guide

ListenUp is a fork of AntennaPod that detects dynamically inserted podcast ads on the phone and skips them.
Branch `listenup` of `maciej-rosiek/ListenUp`; `develop` mirrors AntennaPod. This file overrides `AGENTS.md`
where they disagree.

## Fork rules

- Keep AntennaPod mergeable. New code goes into `adskip/` or into new files; an upstream file gets the smallest
  possible hook (a call, a field, a menu item). Each hook is listed under Architecture, so keep that list true.
- Strings: add English ones to `ui/i18n/src/main/res/values/strings.xml`. User-visible "AntennaPod" is
  replaced at build level by `app/src/main/res/values*/listenup_rebrand.xml`, generated by
  `python3 scripts/listenup_rebrand.py`; rerun it after every upstream merge and after adding a string that says
  AntennaPod. Name ListenUp-only string keys `ad_*` or `listenup_*`.
- Work on `listenup`, commit in small steps, push to `origin`. AntennaPod's PR and issue conventions in
  `AGENTS.md` apply only to PRs aimed at AntennaPod itself.
- `README.md` is ListenUp's own (features, credits, license); on a merge conflict keep ours.

## Architecture

- `adskip/detector` is plain Java with JVM tests, no Android. `Mp3FrameReader` hashes every MP3 frame and reads
  Megaphone's clip tag frames; `DownloadDiffAdDetector` is the pipeline behind the `AdDetector` interface:
  1. host marks: clip tag frames (`FrameHashes.taggedClips`) and the `x-megaphone-payload-2` header
     (`HostAdBreaks`), both from the single downloaded file;
  2. the known-ads library (`KnownAdMatcher`, offset voting over frame hashes);
  3. the feed-duration check: file length minus ads against `itunes:duration`;
  4. only when 3 leaves more than 4 s unexplained: 2, then up to 5, extra copies downloaded in parallel and
     aligned (`SequenceAligner`, patience-style); frames not shared by every copy are ads, and their clips are
     learned into the library (`AdClipLearner`).
  A second detector (on-device AI) is meant to be another `AdDetector` with its own per-podcast switch.
- `adskip/service` is Android: `AdSkipStore` (own SQLite `adskip.db`: segments, analysis, known ads, per-feed
  settings, kept out of AntennaPod's database on purpose), `AdDetection` (entry points), `AdDetectionWorker`
  (WorkManager; waits for Wi-Fi before extra copies), `EpisodeCopyFetcher` (honest User-Agent per copy).
- Hooks into AntennaPod code:
  - `MediaDownloadedHandler.run`: captures the feed's duration before it is overwritten, calls
    `AdDetection.onEpisodeDownloaded`.
  - `HttpDownloader`: keeps the Megaphone header in the request arguments, dropped on resumed downloads.
  - `Media3PlaybackService`: `AdSkipController` (forward-only skip, whoosh cue `R.raw.skip_cue`, undo snackbar,
    30 s revert window, `AdSkipSession` for spans allowed this playback).
  - `ChapterSeekBar.setSegments` and `SegmentOverlayView` in `external_player_fragment.xml`: green ad marks.
  - `AudioPlayerFragment` menu: `AdSegmentListDialog`, `EditAdSegmentDialog`.
  - `FeedSettingsPreferenceFragment`: `AdDetectionPreference`.
  - `MainPreferencesFragment`: neutral "based on AntennaPod" notice instead of upstream's warning.
  - `FeedMultiSelectActionHandler`: "Mark all as played".
  - `app/build.gradle`: app id `com.listenup`, provider authority, `apply from: "listenup.gradle"`.

## Megaphone facts (Rock i Borys, feed https://anchor.fm/s/d2713e0/podcast/rss)

- Ads are stitched in per request at MP3 frame boundaries without re-encoding, so show frames are byte-identical
  across downloads. The number of ads changes per request (2 to 12 clips seen for one episode).
- The same User-Agent re-requested soon gets a byte-identical file; every extra copy needs its own User-Agent.
- Each clip starts with an ffmpeg tag frame whose `Info` magic is overwritten with `55555555`; it holds the
  clip's frame count. The final audio response carries `x-megaphone-payload-2` with every slot's byte range.
- `itunes:duration` is the length without ads; a correct detection leaves under 4 s unexplained.

## Build and test

- Build: `./gradlew :app:assembleDebug`. Use the `free` flavour for anything installed: the app is
  `com.listenup.debug` (debug) or `com.listenup` (release), not `de.danoeh.antennapod.debug`.
- Inside a Claude Code sandbox on raven the JVM prints a cgroup warning that breaks AGP's `jmod` call; export
  `JAVA_TOOL_OPTIONS='-Xlog:disable -Xlog:all=error:stderr'` before Gradle.
- Detector: `./gradlew --console=plain :adskip:detector:test` (seconds). For real files, download copies with
  `curl -sL -A "ListenUp/test (copy N)" -o copyN.mp3 https://traffic.megaphone.fm/<episode>.mp3`, then run
  `java -cp adskip/detector/build/classes/java/main:adskip/detector/build/classes/java/test
  de.danoeh.antennapod.adskip.detector.DetectorCli <declared ms> played.mp3 copy2.mp3 ...`.
- Emulator on raven: SDK in `~/android-sdk`, AVD `listenup_pixel8pro` (Pixel 8 Pro, Android 14).
  `scripts/listenup-emulator.sh` starts it headless (`--window` to show it); it needs the Nix library path the
  script builds. Drive it with `scripts/listenup-ui.sh dump | tap <text> | screenshot <file>`.
- End-to-end on the emulator: `adb shell am start -a android.intent.action.VIEW -d
  feed://anchor.fm/s/d2713e0/podcast/rss com.listenup.debug`, subscribe, podcast settings (gear) → Ad detection
  → tick both, download an episode, wait for `AdDetectionWorker: Found N ads` in logcat. Inspect results with
  `adb exec-out run-as com.listenup.debug cat databases/adskip.db > adskip.db` and sqlite.
- Your phone gets release builds only (Obtainium or `adb install` of the release APK); the debug app stays on
  the emulator.

## Release

- `scripts/listenup-release.sh <major.minor.patch>` on raven: builds the signed `free` release, pushes, creates
  GitHub release `v<version>` with `ListenUp-<version>.apk`. Version code is `major*10000 + minor*100 + patch`.
- Away from raven: run the "ListenUp release" workflow (or push a `v*` tag); it skips when the release already
  has an APK.
- Signing key: `~/.android/listenup-release/` on raven and the `LISTENUP_KEYSTORE_*` repository secrets. It
  stays outside the repository; every release must be signed with it or installed apps stop updating.

## After merging AntennaPod `develop`

1. Resolve conflicts around the hooks listed under Architecture.
2. `python3 scripts/listenup_rebrand.py`, then `./gradlew :app:assembleDebug` and
   `./gradlew :adskip:detector:test`.
3. Run the end-to-end flow on the emulator before releasing.
